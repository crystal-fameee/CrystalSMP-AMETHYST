# Crystal-Amethyst 1.2.3
Paper 1.21.11 / Java 21.

- Natural amethyst geodes: each detected geode has 50% chance to contain exactly one special amethyst, otherwise zero.
- Special amethyst is an oversized glowing amethyst cluster (1.35x visual scale) with purple particles; it drops a custom special-amethyst item.
- Right-click the special amethyst item to convert it into an amethyst seed.
- Seed base growth is 1 hour.
- Darkness (block light <= 7): +25% speed.
- Night (13000-23000): another +25% speed.
- Maximum speed is capped at 1.5x.
- Existing coin/Vault/PlayerPoints features are preserved.
